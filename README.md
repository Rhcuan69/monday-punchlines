## The entry

> On Monday mornings, my bed files for full custody of me. The judge keeps ruling in favor of the alarm clock.

The joke: Monday morning reframed as a custody hearing. The bed wants to keep
you; the alarm clock keeps winning the verdict. A real turn (courtroom, not
complaint), no alarm-clock or coffee cliché, and every word earns its place.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (override the directory with the
`MAKEFUN_OUTPUT_DIR` environment variable for local testing). Pure Python
standard library only — no third-party dependencies — and fully deterministic:
every run writes the exact same bytes.
